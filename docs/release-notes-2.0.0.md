# DPS XML Recovery 2.0.0

Первый portable x86 build: одно приложение обслуживает GUI и внутренний worker-процесс. Поставка onedir не требует установленного Python или прав администратора. Криптографические компоненты ІІТ, ключи и пользовательские данные в поставку не включены.

Проверки релиза охватывают архитектуру PE, состав ZIP, отсутствие запрещённых данных, Tcl/Tk, CA bundle, запуск GUI и worker из собранного EXE. Windows 10/11 и Windows Server 2016 считаются проверенными только после отдельного запуска на соответствующих системах.
