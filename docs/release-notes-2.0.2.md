# DPS XML Recovery 2.0.2

- JSONL IPC теперь ASCII-safe и явно использует UTF-8 в worker, поэтому Unicode-пути не зависят от системной Windows code page.
- Worker до любой записи проверяет SHA-256 канонического recovery-root и запрещает создание неизвестного корневого каталога.
- Inventory/download progress преобразуется к реальным ограниченным счётчикам; неизвестные значения больше не отображаются как `0/0`.
- Coalescing сохраняет последовательность смены фаз.
- Диагностический экспорт содержит только структурированные разрешённые счётчики, статусы и безопасные коды.
