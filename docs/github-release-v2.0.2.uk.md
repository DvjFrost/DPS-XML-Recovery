# DPS XML Recovery 2.0.2

Перший публічний кандидат портативної Windows-програми для відновлення власного архіву XML-документів із приватного API Електронного кабінету ДПС України.

## Що вміє програма

- виконує повний inventory за вибраний період із перевіркою пагінації;
- завантажує основні та пов’язані XML;
- перевіряє XML, SHA-256, manifest і залишкові `.part`;
- продовжує роботу після безпечної зупинки;
- підтримує full, inventory-only та audit-only;
- працює з Unicode-шляхами та формує безпечний діагностичний звіт.

## Перевірка кандидата

- 177 автоматизованих тестів — PASS;
- package audit — PASS;
- реальне відновлення: 135 основних + 212 пов’язаних XML;
- невалідних XML: 0;
- `.part`: 0;
- помилок аудиту: 0;
- фінальний аудит: PASS.

## Перед запуском

1. Повністю розпакуйте ZIP.
2. Перевірте SHA-256 архіву.
3. Переконайтеся, що офіційний комплекс «ІІТ Користувач ЦСК-1» із сумісною x86 `EUSignCP.dll` установлений і налаштований.
4. Запустіть `DPSXmlRecovery.exe` та виконайте перевірку ІІТ.

Python і .NET Runtime встановлювати не потрібно. Компоненти ІІТ, JKS, сертифікати та користувацькі дані до ZIP не входять.

## Відомі обмеження

- Windows 10 x64 перевірено;
- Windows 11 і Windows Server 2016 ще не перевірено;
- EXE не має цифрового підпису і може викликати SmartScreen;
- потрібен установлений сумісний комплекс ІІТ x86;
- програма не імпортує XML у M.E.Doc.

## Безпека

Ключ і пароль КЕП не передаються розробнику. Пароль не зберігається та передається локальному worker-процесу одноразовим Windows anonymous pipe. `EUSignCP.dll` використовується з офіційної локальної інсталяції ІІТ. Авторизація формується локально для взаємодії з приватним API ДПС.

Ці заходи не є гарантією абсолютної безпеки. Захищайте JKS, Windows-обліковий запис і каталог відновлення та не публікуйте діагностику без попереднього перегляду.
