# DPS XML Recovery 2.0.2 — portable x86

Повністю розпакуйте ZIP і запустіть `DPSXmlRecovery.exe`. Python та додатковий runtime не потрібні; права адміністратора для самої програми не потрібні.

Офіційний комплекс «ІІТ Користувач ЦСК-1» із сумісною 32-бітною `EUSignCP.dll` має бути встановлений і налаштований окремо. Компоненти ІІТ, JKS та користувацькі сертифікати до пакета не входять.

Повна інструкція українською міститься в `README.md`, російською — у `README.ru.md`.

Програма створює `portable-data` поруч з EXE. Якщо каталог недоступний для запису, вона запропонує явно вибрати інше розташування. Пароль КЕП не зберігається. У релізному ZIP `portable-data` містить лише інформаційний `README.txt`.

Внутрішній параметр `--worker` призначений лише для запуску робочого процесу самим застосунком.
