# Історія змін

Формат базується на [Keep a Changelog](https://keepachangelog.com/uk/1.1.0/). Проєкт використовує семантичне версіонування.

## [2.0.2] — 2026-10-12

### Виправлено

- Unicode-шляхи в JSONL IPC тепер передаються незалежно від системної Windows code page.
- Worker перевіряє канонічний recovery-root до будь-якого запису і не створює каталог із пошкодженого шляху.
- Progress для inventory і download використовує реальні обмежені лічильники; невідомі значення більше не показуються як `0/0`.
- Порядок зміни фаз зберігається під час coalescing подій.
- Діагностика повертає лише безпечні статуси, лічильники та `error_type`.

### Перевірено

- 177 автоматизованих тестів, frozen mock E2E і package audit.
- Реальне відновлення 347 XML завершилося фінальним аудитом PASS.

## [2.0.1] — 2026-10-11

### Виправлено

- Валідацію діапазону років для відновлення від старішого до новішого року.

## [2.0.0] — 2026-10-11

### Додано

- Портативний GUI на Python x86 і Tkinter.
- Окремий worker-процес і одноразовий secret pipe для пароля КЕП.
- Read-only preflight комплексу ІІТ.
- Режими full, inventory-only та audit-only.
- Portable settings, безпечні журнали та експорт діагностики.
- Self-contained PyInstaller `onedir` збірку для Windows.
